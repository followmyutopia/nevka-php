iOS

Для того, чтобы открыть Невки приложение на iOS, понадобится бесплатное приложение Expo Go из AppStore:


Скачать Expo Go в AppStore

Регистрироваться в нём не нужно, просто скачать, один раз открыть и закрыть.

После этого можно открыть приложение Невки, нажав кнопку ниже:


Открыть приложение Невки 1.8.4

Эта версия работает в приложении Expo Go 54. Если выйдет Expo Go 55, обновите приложение по этой ссылке.
